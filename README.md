**My Contributions**
Developed the end-to-end document parsing pipeline to extract and preprocess financial text from uploaded PDFs.

Implemented image-based text extraction using PyMuPDF, Pillow, and Tesseract OCR to convert visual data into structured text.

Created custom text chunking logic and embedded content using SentenceTransformer (all-MiniLM-L6-v2) for downstream question answering and retrieval tasks.

Handled OCR embedding generation, chunk metadata tagging, and ensured pipeline scalability for large financial documents.
